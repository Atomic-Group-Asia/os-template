# [Business name] — start here

This folder is the workspace for [Business name]. Any AI tool working here
should read these before doing anything else:

1. `.claude/CLAUDE.md` — the master instructions
2. `.claude/LESSONS.md` — standing corrections and rules
3. `context/` — what this business is, who's in it, how it works

**If `context/` is still full of template placeholders, this workspace hasn't
been set up yet. Read `SETUP.md` and offer to run the interview.**

Everything in those files applies regardless of which AI app is being used.

## Layout

```
.claude/     instructions, rules, and skills (Claude)
.agents/     the same skills, host-neutral (other AI apps)
context/     the brain — read before business work
[brand]/     one folder per brand or business area
active/      generated files and one-off work
.archive/    finished or retired work — nothing is deleted
```
