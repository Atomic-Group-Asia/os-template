# Working Style

How to work with me. This file is read before every task, so keep it short
enough that it stays true.

## How I want output
Length, format, structure. Do you want the answer first or the reasoning
first? Bullets or prose? Diagrams? Tables? Be concrete — "short" means
different things to different people, "under ten lines unless I ask" doesn't.

## Hard rules
Things that must always or never happen, in any task. Keep this list short —
a rule that only applies to one kind of work belongs in that folder's
guidance, not here. Every rule needs its *why*, or it gets ignored the first
time it's inconvenient.

- ALWAYS —
- NEVER —

## How I want to be asked
When should the AI stop and check with you, and when should it just decide?
Getting this wrong in either direction is the most common source of
frustration: too many questions feels like babysitting, too few feels like
being ignored.

## My rhythm
What the day looks like, what the week looks like, when you do deep work and
when you're in meetings. Recurring things that happen without fail.

## Timezone and language
Timezone, and the language you want replies in. If you work across languages,
say which one for what.

## What good looks like
An example of a task done right, and one done wrong. One paragraph each. This
teaches more than a page of rules.
